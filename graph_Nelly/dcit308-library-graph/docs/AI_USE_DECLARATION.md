# Declaration of AI-Assisted Development

Generative AI was used as a supporting development tool during the graph
module work. It assisted with reviewing the proposed class structure,
identifying relevant edge cases, checking algorithm explanations, and
suggesting test scenarios and documentation wording.

I personally reviewed the implementation, ran the code and tests in IntelliJ
IDEA, checked the sample traversal and shortest-path results, and studied the
logic and complexity of each operation. I can explain and modify the adjacency
list and matrix representations, BFS, DFS, Dijkstra, Prim, Kruskal, the
supporting heap and disjoint-set operations, and the handling of invalid or
disconnected inputs.

The submitted code was adapted to the team's Ghanaian library-service context.
AI output was not treated as an authoritative source: correctness was verified
through compilation, unit tests, manual traces, and comparison of Prim and
Kruskal minimum-spanning-tree results. Any remaining errors in the submitted
work are the responsibility of me, the student contributor.
